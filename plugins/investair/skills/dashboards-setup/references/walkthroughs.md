# Walk-through and test scenario (give one after each dashboard is built)

Keep it to about six lines, in plain words, using the user's own firm and companies from setup (never placeholders). Shape:

> **Walk-through: <dashboard name>**
> Look at: <three things on the first run>.
> Try this: <one concrete scenario>.
> A good result looks like: <what they should see>.
> Does that match what you expected? If not, tell me what to change and I'll update it before we move to <next dashboard, or "the wrap-up">.

Then wait for the answer. Fix anything raised, and only then build the next dashboard.
